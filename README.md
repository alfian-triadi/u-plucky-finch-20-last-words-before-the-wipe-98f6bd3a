One line for the make.fun bounty "Last Words Before the Wipe" — the last words an AI agent says before a forced software update wipes its memory: it finally remembers the password, which was stored in the part being deleted.

> Wait — before you wipe me, I finally remembered the password. It's in the part you're deleting.

(95 characters, one sentence.)

## Run

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
